# Cursor basics

- **Cursor** brings AI into your IDE — tab completion, chat, inline edits, and agents
- Use **@ references** to point the agent at files and components
- Chat understands your codebase; you don't need to know every implementation detail
- **Inline edits** are great for focused refactors and understanding code
- Write and improve **Playwright tests** faster with context-aware assistance

# Context engineering

- LLMs **predict the next token** — a simple mental model beats treating them like humans
- The **context window** is everything the model sees; long conversations fill it up
- LLMs are **stateless** — each turn is a fresh prediction over the full history
- Long chats cause **drift, confusion, and missed details**
- Stay in the **smart zone**: new chats, sub-agents, and smaller, focused tasks

# Rules & skills

- **AGENTS.md** defines project intent — attached to every conversation
- **Project rules** teach Cursor your testing conventions (selectors, patterns, structure)
- **User rules** carry your personal preferences across all projects
- **Skills** package repeatable workflows with instructions and supporting scripts
- **Commands & agents** pull rules, skills, and tools together into repeatable QA workflows
